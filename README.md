# SideHustle Signal

A fast static website for discovering low-cost side hustle ideas by budget, time, and skill.

## Traffic plan

- Target long-tail search: "side hustle ideas by budget", "online business ideas for teachers", "low cost side hustles".
- Add one new niche page per week for specific audiences.
- Share calculator snippets and idea cards on short-form platforms.
- Capture backlinks by publishing transparent monthly experiments.
